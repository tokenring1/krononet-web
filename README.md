# krononet-web

Krononet uygulamasının herkese açık web sayfaları (landing + yasal metinler).
GitHub Pages ile yayınlanır.

| Sayfa | URL | Play Console alanı |
|---|---|---|
| `index.html` | `/` | Website |
| `privacy.html` | `/privacy.html` | Privacy Policy |
| `hesap-silme.html` | `/hesap-silme.html` | Account deletion / Data deletion URL |
